# QueueFlow — Virtual Queue Token System

A polished, responsive queue-management dashboard built with **HTML, CSS, and JavaScript**.

## Features
- Generate queue tokens and check token status
- Dashboard for currently serving, waiting, total issued, and next token
- Call, skip, and complete tokens
- Responsive desktop and mobile layout
- Saves queue data in browser LocalStorage

## Run the project
Open `index.html` in any modern browser. No installation is required.

## Publish with GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then click **Save**.

## Important
This is a front-end demo. Data is saved only in the current browser and is not shared across devices. A shared production queue would need a backend and database.
